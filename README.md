# GridTrax

## 功能

- **影视搜索与详情**：接入 TMDB，搜索电影、电视剧，查看海报、背景图、简介、评分及分季分集信息。
- **观看状态管理**：支持在看、想看、看过、搁置和抛弃，记录电影及电视剧各季的观看状态和单集进度。
- **集数分页与排序**：在看卡片每页展示 18 集，支持上一页、下一页和正序、倒序排列。
- **移动端标题列表**：存在有效单集短标题时，可在集数网格和标题列表之间切换。
- **追踪筛选与排序**：支持按全部、电视剧、电影筛选，以及按最近互动、名称、TMDB 评分排序。
- **影片网格**：除在看外，各板块的网格视图每页展示 15 部影片；移动端每行 3 部，桌面端每行 5 部，展示海报、年份、电影或季标签及 TMDB 评分。
- **看过时间线**：可在网格和时间线之间切换，并记住所选视图；切回网格保留筛选和页码。时间线展示全部看过记录，按最近操作时间倒序分月、分日，年月栏滚动吸顶并随月份自动替换。同一天的影片在窄屏、中等宽度、宽屏下分别按 1、2、3 列排列。
- **明暗主题**：提供多款暗色主题和 Sunlit Mint 明亮主题，支持切换并记住选择。
- **本地存储与备份**：观看记录保存在当前浏览器的 LocalStorage 中，支持 JSON 导入、导出和旧版备份兼容。导入前校验文件并确认覆盖，不包含账号信息或 API Token；不同设备间通过 JSON 文件手动迁移。
- **响应式布局**：适配手机和电脑，导航栏直接提供搜索、数据备份和主题切换入口。

## 部署

项目为纯前端 SPA，使用 Cloudflare Pages 部署，无需额外后端服务。

### 构建配置

在 Cloudflare 控制台创建 Pages 项目并连接 Git 仓库，设置以下参数：

| 配置项 | 值 |
| --- | --- |
| 构建命令 | `npm run build` |
| 构建输出目录 | `dist` |
| 项目根目录 | 仓库根目录 |
| Node.js | 22.12.0 或更高版本 |

保留根目录的 `wrangler.jsonc`，其中已将 `pages_build_output_dir` 配置为 `dist`。

### TMDB Token

在 Pages 对应部署环境的构建环境变量中添加 TMDB 的 **API Read Access Token**：

```env
VITE_TMDB_BEARER=your_tmdb_read_access_token
```

- 使用完整的 Read Access Token，不是 API Key，也不要添加 `Bearer ` 前缀。
- 无需提交 `.env.local`，网页中也不提供 Token 设置入口。
- 如需预览部署，应为预览环境配置同名变量。
- 修改 Token 后需要重新构建部署，才能更新前端产物。

### 部署与更新

保存配置并部署。后续将代码推送至 Pages 绑定的部署分支，即可触发构建更新。

注意事项：

- `VITE_` 变量会被嵌入浏览器可下载的前端代码，并非服务端秘密。不要将 `.env.local` 或真实 Token 提交到公开仓库。
- 搜索、详情和海报由浏览器直接请求 TMDB，静态部署不会代理这些请求，访问环境需要能够连接 TMDB。
- 观看记录仅保存在当前浏览器，清除站点数据会删除记录，请定期导出 JSON 备份。
