# GridTrax

## 功能

### 影视与人物热门榜

- 支持切换豆瓣、TMDB 来源，以及电影、电视剧榜单。
- 豆瓣展示实时热门前 10 名，TMDB 支持日榜、周榜。
- TMDB 额外提供人物日榜、周榜，展示排名、头像、姓名、职业与代表作品，可进入人物或影视详情。
- 展示海报、片名、原名、年份、上映或首播日期、中文类型、地区、评分及简介，缺失信息自动隐藏。
- 豆瓣与 TMDB 评分分别标注。
- 简介默认显示 4 行，超出后可“展开全文”。
- 支持进入影视详情、站内搜索、手动刷新和加载失败重试。
- 豆瓣影片未匹配到 TMDB 时，可跳转至对应豆瓣影片页面。
- 从详情页返回或刷新页面后，保留榜单选项。

### 影视列表

- 宽屏通过右上角列表图标进入，窄屏通过榜单菜单进入，与实时热门榜分开展示。
- 支持电影、电视剧两种类别切换。
- 电影提供正在热映、热门、高分及即将上映四种列表，按中国地区展示。
- 电视剧提供今日播出、正在播出、热门及高分四种列表。
- 支持上一页、下一页浏览，展示海报、名称、年份、类型、地区、评分及简介。
- 播出列表统一使用北京时间，支持刷新和加载失败重试。
- 点击影片可进入详情，返回或刷新页面后保留所选类别、列表及页码。

### 筛选找片

- 提供独立的筛选找片页面，可切换电影与电视剧，宽屏从顶部筛选图标进入，手机端从浏览菜单进入。
- 支持组合筛选类型、制片地区、上映或首播年份和 TMDB 评分，多选类型时匹配任一类型，两类作品使用各自的类型选项。
- 更多条件支持原始语言、最低评分人数和片长或单集时长范围，评分、人数和时长均可通过滑块调整。
- 支持按热度、评分、上映或首播时间、评分人数和标题排序，电影额外支持票房排序；每组均可切换升序、降序。
- 条件统一应用，支持重置、逐项移除，以及输入范围校验。
- 切换电影、电视剧时重置筛选条件和页码，避免条件混用。
- 手机端使用筛选抽屉，结果每行三部，海报缺失时展示占位图。
- 支持分页和进入详情，返回后恢复筛选、页码与滚动位置；刷新或分享网址保留已应用条件。
- 筛选结果限量缓存五分钟，不写入本地观看记录，加载失败可重试。

### 影视搜索与详情

- 接入 TMDB，支持分页搜索电影、电视剧和人物。
- 人物搜索结果展示头像、姓名、职业和代表作品；姓名过长自动换行，点击代表作品可进入影视详情。
- 可查看海报、背景图、简介、评分及分季分集信息。
- 电影和电视剧均展示语言、制片地区及出品公司 Logo，电视剧额外展示播出平台 Logo。
- 无有效评分时不显示评分，年份为空时不显示标签或占位，电影没有有效片长时不显示片长。
- 请求超时或失败时可重试，快速切换搜索不会显示旧结果。
- 影片资料共用有容量和有效期限制的内存缓存。

### 演职人员

- 电影和电视剧详情页均可查看导演、编剧、制片等幕后人员及主要演员。
- 演职人员位于简介之后，电影中在观看状态之前，电视剧中在全部季数之前。
- 主要演员默认展示前 10 位，单行横向排列，显示照片、姓名和饰演角色。
- 手机端左右滑动查看，电脑端可使用左右箭头。
- 默认姓名和角色各占一行，过长省略；“查看全部”中完整显示，并可切换演员、幕后分类。
- 电视剧同一演员的多个角色合并展示，幕后人员按职务分组。
- 点击电影、电视剧详情页中的演职人员，可进入对应人物详情页。

### 人物详情

- 展示头像、姓名、职业、性别、出生日期、年龄、出生地、又名和人物简介，缺失资料自动隐藏。
- 已故人物展示逝世日期，并根据有效日期计算享年。
- 有有效链接时，可访问人物个人网站和 IMDb 页面。
- 人物简介默认显示 10 行，又名默认显示 4 行，超出后可“展开全文”并收起。
- 浏览人物资料不会创建或修改观看记录。

### 人物影视作品

- 在人物简介下方展示参演及幕后作品，按年份从新到旧分组，日期未知的作品统一放在末尾。
- 展示海报、片名、电影或电视剧类型、上映或首播日期、有效评分，以及饰演角色和幕后职务。
- 同一作品的多个角色和职务合并展示，常见幕后职务使用中文名称。
- 支持按全部、电影、电视剧切换，并可按职务和年份筛选，显示筛选后的作品数量。
- 移动端每行一部，电脑端两列展示，仅在年份分组之间保留分隔线。
- 点击作品可进入对应影视详情页。
- 作品与人物资料并行加载，作品列表独立缓存 5 分钟，加载失败可重试。

### 猜你喜欢与相似影片

- 电影和电视剧详情页均提供“猜你喜欢”和“相似”两个独立列表。
- 电影中位于观看状态之后，电视剧中位于全部季数之后，“相似”在“猜你喜欢”下方。
- 每个列表按返回顺序保留前 10 部，展示海报、片名、年份和有效评分。
- 单行横向排列，手机端左右滑动，电脑端可使用左右箭头，点击可进入对应影片详情页。
- 独立加载、重试并缓存 5 分钟，一个列表失败不影响另一个列表。
- 无相似影片时显示空状态；电影无推荐时显示空状态，电视剧无推荐时隐藏该列表。

### 电视剧分季详情

- 各季可独立展开、收起，集数在展开后按需加载。
- 展示本季海报、首播日期、总集数、有效评分和独立简介。
- 单季作品的简介与整剧相同时，不重复展示。

### 简介展开与收起

- 电影、电视剧整剧及人物简介默认最多显示 10 行。
- 热门榜、电视剧每季及单集简介默认最多显示 4 行。
- 人物又名默认最多显示 4 行。
- 根据实际排版是否超过默认行数显示“展开全文”，不按字数判断。
- 展开后可收起，窗口宽度变化时自动重新判断。

### 观看状态管理

- 支持在看、想看、看过、搁置和抛弃五种状态。
- 记录电影及电视剧各季的观看状态和单集进度。
- 点击集数切换已看，长按或右键可选择“看到这里”批量标记。

### 集数分页与排序

- 在看卡片和电视剧详情页的每季集数，均每页展示 18 集。
- 支持上一页、下一页和正序、倒序排列。
- 分页不影响整季观看进度统计。

### 移动端标题列表

- 存在有效单集短标题时，可在集数网格和标题列表之间切换。

### 单集详情视图

- 电视剧详情页可切换单集详情，查看短标题、首播日期、本集时长和简介。
- 缺失字段及无效时长不显示。
- 上方左侧为集数按钮，右侧为标题和日期、时长，下方通栏展示首行缩进的简介。
- 支持分页、排序及观看标记，切换视图保留当前页码和顺序。
- 阅读或展开简介不会改变观看记录。

### 追踪筛选与排序

- 支持按全部、电视剧、电影筛选。
- 支持按最近互动、名称、TMDB 评分排序。

### 影片网格

- 除在看外，各板块的网格视图每页展示 15 部影片。
- 移动端每行 3 部，桌面端每行 5 部。
- 展示海报、年份、电影或季标签及 TMDB 评分。
- 电视剧年份取对应季的首播年份，不使用整部剧的首播年份。
- 多季电视剧优先展示本季评分，没有有效评分时回退整剧评分；仅一季时使用整剧评分。
- 手机端过长片名仅在进入可视区域后向左循环滚动，桌面端使用省略号。
- 年份和评分优先从本地资料缓存恢复，再按需后台更新，不改变观看记录和最近互动时间。

### 看过时间线

- 可在网格和时间线之间切换，并记住所选视图。
- 切回网格时保留筛选和页码。
- 时间线展示全部看过记录，按最近操作时间倒序分月、分日。
- “看过”标题和年月栏分层吸顶，下个月份到达时替换上个月份。
- 日期与星期下方展示当天记录数量。
- 同一天的影片在窄屏、中等宽度、宽屏下分别按 1、2、3 列排列。

### 明暗主题

- 提供多款暗色主题和 Sunlit Mint 明亮主题。
- 支持切换主题并记住选择。

### 本地存储与备份

- 观看记录保存在当前浏览器的 LocalStorage 中，保存失败会提示并支持重试。
- 支持 JSON 导入、导出和旧版备份兼容。
- 导入前校验文件并确认覆盖，保留一份本地恢复快照。
- 显示最近生成备份的时间。
- 备份不包含账号信息或 API Token，不同设备间通过 JSON 文件手动迁移。
- 本地恢复快照不能替代下载的 JSON 备份。

### 浏览位置恢复

- 新进详情页从顶部开始。
- 通过浏览器历史返回时，恢复追踪页的网格页码和滚动位置。
- 右下角支持一键回到顶部。

### 响应式布局

- 适配手机和电脑。
- 导航栏直接提供搜索、数据备份和主题切换入口。

## 技术栈

| 类别 | 技术 |
| --- | --- |
| 前端框架 | React 19 + TypeScript 5 |
| 构建工具 | Vite 7 |
| UI 与样式 | Material UI 7 + MUI Icons + Emotion |
| 路由 | React Router 7 |
| 状态管理 | Zustand 5，使用 persist 持久化 |
| 网络请求 | Axios |
| 数据来源 | TMDB API + 豆瓣电影、电视剧实时热门榜 |
| 榜单服务 | Cloudflare Pages Functions，成功结果缓存 5 分钟 |
| 数据存储 | 浏览器 LocalStorage |
| 代码检查与测试 | ESLint 9 + TypeScript + Node.js 内置测试；`npm run test` 运行回归测试，`npm run check` 执行检查、测试和构建 |
| 部署平台 | Cloudflare Pages |

## 项目结构

```text
GridTrax/
├─ functions/          Cloudflare Pages Functions，仅承载榜单接口
│  └─ api/hot/         movies.ts（电影榜单）、tv.ts（电视剧榜单）
├─ server/             hotMovies.ts，榜单抓取与解析的共享逻辑，供 Functions 与 Vite 开发服务器复用
├─ public/             静态资源，_routes.json 限定只有榜单接口走 Functions
├─ src/
│  ├─ api/             tmdb.ts，TMDB 请求封装
│  ├─ components/      UI 组件（PascalCase），如 MediaCard、EpisodeGrid、MediaCredits；episodeTitle.ts 为集名工具
│  ├─ hooks/           复用逻辑：异步资源、榜单、首页资料补全、视口可见性
│  ├─ pages/           路由页面：HomePage、HotMoviesPage、SearchPage、MovieDetailPage、TvDetailPage、PersonDetailPage
│  ├─ store/           Zustand 状态：useProgressStore（观看进度）、useThemeStore（主题）
│  ├─ theme/           MUI 主题与多套配色定义
│  ├─ types/           数据类型定义：index.ts（业务模型）、hotMovies.ts（榜单模型）
│  ├─ utils/           纯函数工具（camelCase）：缓存、榜单匹配、进度存储、备份、资料归一化等
│  ├─ App.tsx          路由与布局装配
│  ├─ main.tsx         应用入口
│  └─ index.css        全局样式
├─ tests/              Node.js 内置测试的回归用例，与 src/utils 下的工具模块一一对应
├─ vite.config.ts      开发与构建配置
├─ eslint.config.js    ESLint 配置
├─ tsconfig.json       TypeScript 配置（含 tsconfig.app.json、tsconfig.node.json）
├─ wrangler.jsonc      Cloudflare Pages 配置，输出目录指向 dist
└─ index.html          SPA 入口页面
```

说明：

- `src/` 为纯前端代码，只依赖 TMDB。榜单是唯一需要服务端参与的部分：`server/hotMovies.ts` 存放抓取与解析逻辑，`functions/api/hot/*.ts` 将其暴露为 `/api/hot/movies`、`/api/hot/tv`，Vite 开发服务器也复用同一份逻辑，因此本地 `npm run dev` 与线上行为一致。
- `src/utils/` 下的模块保持无副作用、不依赖 React，便于被 `tests/` 直接导入测试，无需构建或浏览器环境。

## 部署

项目使用 Cloudflare Pages 部署：React SPA 提供界面，仓库内的 Pages Functions 转发豆瓣榜单，无需单独部署后端。

### 构建配置

在 Cloudflare 控制台创建 Pages 项目并连接 Git 仓库，设置以下参数：

| 配置项 | 值 |
| --- | --- |
| 构建命令 | `npm run build` |
| 构建输出目录 | `dist` |
| 项目根目录 | 仓库根目录 |
| Node.js | 22.12.0 或更高版本 |

保留根目录的 `wrangler.jsonc`，其中已将 `pages_build_output_dir` 配置为 `dist`。

同时保留 `functions/` 和 `server/` 目录，Pages 连接 Git 仓库部署时会自动构建电影和电视剧榜单接口 `/api/hot/movies`、`/api/hot/tv`。`public/_routes.json` 限定只有这两个路径调用 Functions，其他页面仍按静态资源提供。仅上传 `dist` 静态文件不能包含榜单服务。

本地安装依赖后使用 `npm run dev`，Vite 会复用榜单服务逻辑；`vite preview` 仅预览静态构建，不提供榜单接口。

### TMDB Token

在 Pages 对应部署环境的构建环境变量中添加 TMDB 的 **API Read Access Token**：

```env
VITE_TMDB_BEARER=your_tmdb_read_access_token
```

- 使用完整的 Read Access Token，不是 API Key，也不要添加 `Bearer ` 前缀。
- 无需提交 `.env.local`，网页中也不提供 Token 设置入口。
- 如需预览部署，应为预览环境配置同名变量。
- 修改 Token 后需要重新构建部署，才能更新前端产物。

### 部署与更新

保存配置并部署。后续将代码推送至 Pages 绑定的部署分支，即可触发构建更新。

注意事项：

- `VITE_` 变量会被嵌入浏览器可下载的前端代码，并非服务端秘密。不要将 `.env.local` 或真实 Token 提交到公开仓库。
- 搜索、详情和海报由浏览器直接请求 TMDB，静态部署不会代理这些请求，访问环境需要能够连接 TMDB。
- 豆瓣榜单由服务端匿名请求，不需要配置或提交个人 Cookie。成功结果缓存 5 分钟，刷新可能仍返回缓存；“获取于”是抓取时间，不是豆瓣更新时间。此接口并非稳定开放 API，如豆瓣限制访问或更改结构，页面会提示重试，不会展示伪造的榜单数据。
- 热门榜分别标注豆瓣和 TMDB 评分；详情和追踪页继续使用 TMDB 评分，两者不会混用，也不会将浏览榜单操作写入观看记录。
- 观看记录仅保存在当前浏览器，清除站点数据会删除记录，请定期导出 JSON 备份。
